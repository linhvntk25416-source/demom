Blood Donation Management System (Hệ thống Quản lý Người Hiến Máu)
Đây là một ứng dụng nhỏ được viết bằng Python, giúp quản lý danh sách thông tin người hiến máu, hỗ trợ việc lưu trữ, tìm kiếm và điều phối nguồn máu một cách hiệu quả.

🚀 Tính năng chính
Thêm người hiến máu mới: Lưu trữ thông tin chi tiết (Họ tên, Nhóm máu, Số điện thoại, v.v.).

Quản lý danh sách: Xem toàn bộ danh sách người hiến máu đã đăng ký.

Xóa/Cập nhật: Chỉnh sửa thông tin hoặc xóa dữ liệu khi cần thiết.

Lưu trữ dữ liệu: Dữ liệu được lưu dưới dạng file JSON (nguoihien.json) để đảm bảo không bị mất khi tắt ứng dụng.

🛠 Công nghệ sử dụng
Ngôn ngữ: Python 3.x

Thư viện: json, os (Xử lý file)

Cấu trúc dữ liệu: List, Dictionary, Object-Oriented Programming (OOP).

📂 Cấu trúc mã nguồn
Cdsnguoihien.py: Chứa lớp xử lý logic nghiệp vụ (thêm, xóa, lưu, đọc dữ liệu).

Cnguoihien.py: Định nghĩa đối tượng Người hiến máu.

nguoihien.json: File cơ sở dữ liệu lưu trữ thông tin.

... (Các file giao diện/xử lý khác).

💻 Cách cài đặt và chạy
Đảm bảo bạn đã cài đặt Python.

Clone repository này về máy:

Bash
git clone https://github.com/ten-cua-ban/demom.git
Chạy file chính (ví dụ run_app.py hoặc main.py tùy file của bạn):

Bash
python run_app.py
📝 Ghi chú
Dự án này được thực hiện nhằm mục đích học tập về cách quản lý dữ liệu file, xử lý đối tượng trong Python và làm quen với quy trình làm việc Git/GitHub.
